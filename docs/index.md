# Downloading, Installing, and Licensing ArcGIS Pro

This tutorial goes over how to download, install, and license ArcGIS Pro with your UTORid.

Please be advised that ArcGIS Pro is also [available on library computers](https://mdl.library.utoronto.ca/technology/computers-with-gis-software) on the St George campus.

[Installing ArcGIS Pro](#installing-arcgis-pro)    
[Licensing ArcGIS Pro](#licensing-arcgis-pro)  

## Downloading ArcGIS Pro
{: #downloading-arcgis-pro}

1. Go to <https://utoronto.maps.arcgis.com/> and create/login to your ArcGIS account (select “ArcGIS Online (University of Toronto)” then sign in using your UTORid and password).
2. Select your name in the top right-hand corner of the screen. From the menu that appears, click My Settings.  
<img src='{{ '/assets/images/arcgispro_dl_004.png' | relative_url }}' alt='Account popup with My settings highlighted' title='' width='400' height='278' />
3. On the left sidebar, click on Licenses  
<img src='{{ '/assets/images/arcgispro_dl_005.png' | relative_url }}' alt='My settings menu with Licenses highlighted' title='' width='400' height='423' />
4. Scroll down until you see ArcGIS Pro. There should be a Download button on the same row. Click it.  
<img src='{{ '/assets/images/arcgispro_dl_006.png' | relative_url }}' alt='Licensed products menu with ArcGIS Pro download button' title='' width='400' height='292' />
5. The default option is to download the latest version of ArcGIS Pro. Leave it as is and click Download.  
<img src='{{ '/assets/images/arcgispro_dl_007.png' | relative_url }}' alt='Download popup with default settings (ArcGIS Pro 2.5) and Download button' title='' width='400' height='345' />

## Installing ArcGIS Pro
{: #installing-arcgis-pro}
 

*Note: if you receive a message stating that you need to install the Microsoft .NET Framework 4.8, please download it from this* [*.NET 4.8 download page*](https://desktop.arcgis.com/en/system-requirements/latest/microsft-net-framework-downloads.htm) *and then follow this* [*video showing how to install .NET*](https://www.youtube.com/watch?v=RuKmzQZ-Qjw)*.*  
*If you need to install the Microsoft .NET Framework 6.0, please download it from this* [*.NET 6.0 download page*](https://dotnet.microsoft.com/en-us/download/dotnet/thank-you/runtime-desktop-6.0.5-windows-x64-installer)*.*

1. Double click on ArcGISPro_25_xxxxxx.exe (Different versions will have different digits in the file name.) A popup window will notify you that the files have been extracted. Click close to begin setup.
2. It will ask you where you want to save it, you will need to go back to this folder in the next step, please remember where you select as your destination folder.
3. In this case the files were saved to the C: in a folder name ArcGISPro, then click OK.  
<img src='{{ '/assets/images/arcgispro_install_003.png' | relative_url }}' alt='Example file directory, installing ArcGIS Pro in the C:/ drive.' title='' width='300' height='345' />
4. Navigate to where you want the files saved. In this case the c:\ArcGISPro and click next.  
<img src='{{ '/assets/images/arcgispro_install_004.png' | relative_url }}' alt='Progress bar showing files being unpacked' title='' width='400' height='311' />

    The files will unpack to the new directory.
5. Click close  
<img src='{{ '/assets/images/arcgispro_install_005.png' | relative_url }}' alt='Popup notifying user that the files have been extracted' title='' width='400' height='310' />
6. The welcome to the ArcGIS Pro setup displays, click next.  
<img src='{{ '/assets/images/arcgispro_install_006.png' | relative_url }}' alt='Popup displaying beginning of setup, with Next highlighted' title='' width='400' height='306' />
7. Click I accept the master agreement, then next.  
<img src='{{ '/assets/images/arcgispro_install_007a.png' | relative_url }}' alt='Master Agreement, with Accept and Next highlighted' title='' width='400' height='305' />
8. The software will copy to the destination folder, then click next.  
<img src='{{ '/assets/images/arcgispro_install_008.png' | relative_url }}' alt='Popup with destination folder listed' title='' width='400' height='305' />
9. Click install.  
<img src='{{ '/assets/images/arcgispro_install_009.png' | relative_url }}' alt='Setup window with Install highlighted' title='' width='400' height='305' />
10. Click finish.  
<img src='{{ '/assets/images/arcgispro_install_010.png' | relative_url }}' alt='Setup window stating that ArcGIS Pro has been successfully installed.' title='' width='400' height='306' />
11. ArcGIS Pro should launch.

    <img src='{{ '/assets/images/arcgispro_install_011.png' | relative_url }}' alt='ArcGIS Pro main menu' title='' width='400' height='233' />

    The ArcGIS Pro application should open. If not search in your task bar “ArcGIS Pro”, Click to start the program.

    <img src='{{ '/assets/images/arcgispro_install_011a.png' | relative_url }}' alt='Finding ArcGIS Pro in the start menu (on Windows)' title='' width='300' height='401' />

 

## Licensing ArcGIS Pro
{: #licensing-arcgis-pro}

1. Start ArcGIS Pro  
<img src='{{ '/assets/images/arcgispro_license_001.png' | relative_url }}' alt='ArcGIS Pro startup logo' title='' width='400' height='195' />
2. ArcGIS Pro will ask you to sign in using ArcGIS Online account information. **Click on Your ArcGIS organization's URL**.  
<img src='{{ '/assets/images/image_69.png' | relative_url }}' alt="ArcGIS sign-in dialog. Two options: 'ArcGIS login' or 'Your ArcGIS organization's URL'." title='' width='420' height='333' />
3. Type in **utoronto** next to .maps.arcgis.com  
<img src='{{ '/assets/images/arcgispro_license_003.png' | relative_url }}' alt="Adding utoronto to the organization's URL" title='' width='400' height='317' />
4. Click on ArcGIS Online (University of Toronto)  
<img src='{{ '/assets/images/arcgispro_license_004.png' | relative_url }}' alt='Clicking on ArcGIS Online (University of Toronto) sign in option' title='' width='400' height='287' />
5. Using your UTORid to login  
<img src='{{ '/assets/images/arcgispro_license_005.png' | relative_url }}' alt='Signing in using UTORid' title='' width='400' height='317' />
6. You may get a warning sign showing your account does not have an ArcGIS Pro Named User license assigned. If this happens, click on ok.  
<img src='{{ '/assets/images/arcgispro_license_006.png' | relative_url }}' alt='Ignoring the warning popup' title='' width='400' height='199' />

That’s it! You should now see your ArcGIS Online username appear in the top right corner.
